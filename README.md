# Society Ledger downloads

Society Ledger is a desktop app for stokvels, burial societies and savings clubs. It keeps members and their dependants, monthly contributions (cash or bank rates, with fines for missed months), payouts and expenses, and prints the contribution register, payout schedule and member statements. Everything stays on your own computer.

**[Download Society Ledger →](https://github.com/Farisanipaul/society-ledger-releases/releases)**

Each release lists which file to download for Windows or Mac, and what to do the first time you open it.

This repository holds the installers only.
